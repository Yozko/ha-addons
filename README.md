# ha-addons

Personal Home Assistant add-on repository.

Add it in Home Assistant under **Settings → Add-ons → Add-on Store → ⋮ →
Repositories** with this URL:

```
https://github.com/Yozko/ha-addons
```

| Add-on | |
| --- | --- |
| [Secret Santa](secretsanta/) | Family Secret Santa, published through Tailscale Funnel. |

The add-ons contain no personal data: settings and data stay in Home Assistant.
